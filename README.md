# CyberShield AI - Actividad Unidad II

Proyecto FrontEnd para la plataforma integral de ciberseguridad para PYMEs en México.

## Alcance de la Unidad II

Se continuó el desarrollo realizado en la Unidad I y se agregó funcionamiento dinámico mediante JavaScript puro. El alcance corresponde al FrontEnd de la primera iteración, sin backend ni base de datos real.

## Formularios solicitados en el ejemplo

1. **Formulario de inicio de sesión** (`login.html`): valida usuario y contraseña de demostración.
2. **Formulario con diversos campos y validación** (`incidentes.html`): registra de forma simulada un incidente con tipo, fecha, severidad, descripción y responsable.
3. **Formulario con un solo mensaje de validación** (`validacion.html`): confirma si la validación dinámica de un módulo fue realizada correctamente.

## Funciones dinámicas agregadas

- Validación de login.
- Almacenamiento local demostrativo con `localStorage`.
- Filtros de alertas por severidad.
- Búsqueda de alertas por texto.
- Panel lateral con detalle de alerta.
- Cambio de estado de alerta.
- Escalamiento de alerta a incidente.
- Modal de registro de incidente con validación de campos.
- Formulario final de validación con mensaje único.
- Generación simulada de reporte ejecutivo.
- Mensajes emergentes tipo toast.
