# Plataforma de Ciberseguridad para PYMEs

## Descripción

Primera iteración funcional de una plataforma de ciberseguridad desarrollada en Java.

El sistema implementa:

- Hash seguro de contraseñas con BCrypt.
- Autenticación multifactor OTP.
- Generación y validación de JWT.
- Arquitectura modular.

---

## Tecnologías utilizadas

- Java 17
- Maven
- IntelliJ IDEA
- JJWT
- BCrypt
- Bouncy Castle
- java-otp
